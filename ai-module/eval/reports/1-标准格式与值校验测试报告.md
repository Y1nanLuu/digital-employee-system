# 报告一：标准格式与值校验测试（单元级）

> 测试人：夏一洲 · 2026-11-06 ~ 11-09 · 对应 PRD FR02/FR03/F03/F04、验收用例 AC08/AC12/AC13
> 性质：工程回归测试（与模型评测分开报告，依据 PRD 4.4）

## 一、测试范围

**金额格式边界**（提取层，AC13 点名）：

| 输入形态 | 期望行为 | 结果 |
|---|---|---|
| `1500元` / `3275元`（无千分位） | 完整提取，不得截断为前三位 | ✅ |
| `0.50元` | 忠实提取 0.50，不得识别成 50 | ✅ |
| `-50元` | 忠实保留负号，不得变正；终值置空并留违规 | ✅ |
| `¥3,275.00` / `6,820.50元` / `12,000元` / `1,234,567.89`（千分位/货币符号） | 正确归一化 | ✅ |

**值校验七类非法值**（FR03 点名：模型/规则输出的非法值不得视为正确提取）：

| 非法值 | 违规码 | 行为 |
|---|---|---|
| 布尔金额 `true` | amount_not_boolean | 剔除+留痕 |
| 负金额 | amount_not_positive | 剔除+留痕 |
| 零 | amount_not_positive | 剔除+留痕 |
| 三位小数 `1.001` | amount_precision | 剔除+留痕 |
| 非法日期 `2026-13-45` | expense_date_invalid | 剔除+留痕 |
| 未来日期 `2099-01-01` | expense_date_future | 剔除+留痕 |
| 未知类别 `娱乐` | expense_type_unknown | 剔除+留痕 |

| # | 缺陷 | 根因 | 修复提交 |
|---|---|---|---|
| 1 | 无千分位 4 位金额截断为前 3 位（1500→150） | 金额正则第一分支千分位组可为零次，前缀匹配即成功 | 7a0226a |

| 4 | 三位小数截断为两位后四舍五入，值校验无从拦截（1.001→1.00 静默通过） | 正则小数位限死两位 + 提取层取整销毁证据（评测发现） | 296209b |
