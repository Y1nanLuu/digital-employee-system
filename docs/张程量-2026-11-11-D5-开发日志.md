### 合并后验证与修复

1. 本地 Python 3.14 无法安装 `rapidocr-onnxruntime`（要求 <3.13），因此 OCR 用例改在容器内（Python 3.11）验证；本地非 OCR 用例 179 项通过、1 项因缺 OCR 失败。
2. 容器构建首次失败：`apt-get` 装 `libgl1`/`libglib2.0-0` 报找不到包。定位为两层原因——`python:3.11-slim` 现在指向 Debian 13（`libglib2.0-0` 改名 `t64`），以及容器内访问 `deb.debian.org` 被拒。修复：基础镜像钉为 `python:3.11-slim-bookworm`，并给 Dockerfile 加可选 `APT_MIRROR` 构建参数（默认官方源，本机用 `mirrors.aliyun.com`）。
3. Docker Desktop 的 WSL 后端在多次重启后卡死，用 `wsl --shutdown` 后重启恢复。
