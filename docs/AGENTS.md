# 开发日志保留规则

用户要求：之前的日志要保留，每天的都要保留；后续要求将周勃的日志合成一份。

- 已有开发日志必须保留，不得删除，也不得用新一天的报告覆盖。
- 周勃统一使用 `周勃-开发日志汇总.md`，每天按实际日期追加独立章节，不再重复新建单独日报。其他成员沿用各自命名方式，同样保留每日记录。
- 日志记录实际开发日期；任务编号（例如 D2）可以写入标题，但不能代替实际日期。不为没有记录的日期编造日志。
- 同一天的补充内容追加到当天章节，并注明补充时间。历史结论需要纠正时，追加更正说明及依据，保留原始记录。
- 11月5日与11月8日的原始内容已合入汇总文件，旧独立文件由用户移除，不重新建立；相关阅读链接统一指向汇总。
- 本规则针对开发日志；API、架构、部署等当前状态文档可随代码正常更新。
- 汇总文件按日期追加完整记录，不覆盖之前日期；新增每日记录时更新下表索引。
