## 可复现执行

在项目根目录执行，测试使用隔离数据库，不清空正在运行的系统：

```powershell
& .venv/Scripts/python.exe -m pytest -c backend/pytest.ini backend/tests ai-module/test_extractor.py -q
& .venv/Scripts/python.exe scripts/generate_enterprise_cases.py
& .venv/Scripts/python.exe scripts/verify_enterprise_rules.py
cd frontend
npm.cmd run build
```

生成器按执行当天上海日期构造费用及住宿日期。test-cases.jsonl共240项：180类别金额、18住宿、3查验、3查重、10流程、12校验、6存储、8识别。后42项包含操作规格，须按下述流程人工或另写自动化执行；verify_enterprise_rules.py仅自动执行前198项。

## 金额与制度测试

九类费用分别覆盖0.01、0.50、99.99、100、199.99、200、299.99、300、399.99、400、499.99、500、999、1000、1000.01、1999.99、2000、2000.01、4999.99、5000元。另测0、负数、5000.01、多于两位小数、科学计数法、NaN、布尔值、空值。票面总额可超过5000，申报金额单独限制。

住宿按两种职级、北京/杭州/佛山三类城市，测标准减0.01、等于标准、加0.01；添加跨日、零晚、未知城市、日期倒置。补测招待人数及人均/单次限额、餐补含首尾日期和已供餐扣除、通讯月份、办公收货、培训业务关联、软件服务期间与合同、其他类别人工依据。业务用途必须随金额变化同步修改，避免将矛盾样本误作正常样本。

制度版本测试至少保留原版与新参数版：复制machine JSON，以新version修改auto_limit等参数，通过ENTERPRISE_POLICY_FILE启动隔离环境。原任务继续引用旧版本，新任务使用新版本；同version更改内容应拒绝发布。不要在正式演示数据库反复改原版参数。

## 模拟财务与三种防重

默认合成查验台账日期2026-11-01：26000000000000000001金额300有效；26000000000000000002金额50无效；26000000000000000003金额1000有效。号码、日期、总额须匹配；任何真实用户发票默认unknown，转人工。页面明确显示模拟查验。

1. 提交防重：同request_id同正文重放返回原任务；同标识改正文冲突；断网结果未知时查询原任务，避免另建任务。
2. 重复票据：同号码/代码再次提交，以及同原文件换号码，均应阻止重复；退回后原任务重提排除自身；同人同日同金额但不同票号仅疑似重复转人工。覆盖并发和写回后重启。
3. 发票查验：valid/invalid/unknown分别测试，号码格式通过仍须查台账；金额或日期不符不能当有效。工具超时、重试和不可用须留下日志并可恢复。

## 真实模型评测交接

至少取200条独立脱敏或合成输入，包含正常、金额边界、缺字段、其他类别、用途矛盾和工具异常。先由人工标注字段、制度引用、初审结论及预期路由，再用实际模型执行，保存模型名、配置版本、时长、原始结构化输出和最终规则结果；统计字段准确率、引用有效率、正确路由率、耗时及失败/降级率。禁止将198条纯规则结果填入LLM准确率。

模型必须在解析和结构化初审两个位置留证；初审只引用本次检索条款。输出非法JSON、虚构引用、超时或缺密钥时转人工。模型“通过”仍受预算、重复、无效票据等硬约束控制。批测会消耗API额度，应在隔离环境限速执行。

## 员工及审批闭环

员工上传并核对→提交→未知查验进入待审批→审批人写明缺项并退回→员工在原task_id修改→填写修改说明并重提→revision加1、原快照保留→重新检索和查询全部工具→审批通过前再次查工具→写回并完成。审批人字段保持只读，不能替员工改金额或材料。覆盖退回理由为空、越权修改、非退回重提、重放、刷新/重启、附件替换后旧件可审计等情况。

## 文件与用户体验

一票一文件，可含同一票的最多5页；单文件5MB、图片20MP以内，一批最多10张。逐张核对提交，已提交项只读；中间损坏或识别失败不丢其余票。确认文件原字节、摘要、本人权限、关联审批人权限、匿名禁止、替换后旧件留存及备份恢复。含多张独立发票的单PDF列为范围外输入，提示用户拆分。

按AC51—55执行：桌面与390px手机布局、首屏引导、错误金额即时提示、离线时禁提且保留输入、草稿重试、Tab焦点可见、主要按钮44px、预览折叠与放大、拒绝确认可取消、点击处理中反馈。补充NVDA等真实读屏与真实慢设备人工检查；自动化结果只覆盖已执行项。
